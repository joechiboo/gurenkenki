# 紅蓮劍姬 - 地城試煉

單一 HTML 檔的 2D 俯視角動作遊戲。可選角色深入地下城，強調打擊感（hitstop 凍幀、螢幕震動、擊退、震動回饋），支援手機觸控與鍵盤操作。

> 個人同人習作，非官方、非商業。所有程式碼與圖形皆為原創（Canvas 程序繪製，無任何官方素材）。角色靈感來自《無職轉生》艾莉絲與《鬼滅之刃》我妻善逸。

## 遊玩

直接用瀏覽器開啟 `index.html`，無任何依賴、無需建置。

啟用 GitHub Pages 後即可用網址遊玩（Settings → Pages → Branch: main / root）。

## 操作

| 動作 | 觸控 | 鍵盤 |
| --- | --- | --- |
| 移動 | 左搖桿 | WASD / 方向鍵 |
| 攻擊（自動索敵、三連斬） | 「斬」鍵或點畫面 | J / 空白鍵 |
| 衝刺（無敵幀） | 任意方向快速滑動 | K / Shift / 方向鍵連按兩下 |
| 奧義 | 各招獨立按鈕 | Q / E / R / T / F |

## 角色

### 艾莉絲（劍神流・光刀三式）

- Lv5「無音之太刀」Q・直線居合斬（冷卻 8 秒）
- Lv10「光之太刀」E・多目標連斬，單體連續穿斬（冷卻 12 秒）
- Lv15「光返し」R・折返雙輪＋終結十字斬＋斬滅彈幕，擊殺冷卻 -1 秒（冷卻 18 秒）

### 我妻善逸（雷之呼吸・六式，每 3 級學一型）

- Lv3 壹之型「霹靂一閃」Q・神速直線居合（6 秒）
- Lv6 貳之型「稻魂」E・正面扇形五連斬（9 秒）
- Lv9 參之型「聚蚊成雷」R・迴旋斬並震碎周圍彈幕（11 秒）
- Lv12 肆之型「遠雷」T・落雷狙擊遠處敵人（13 秒）
- Lv15 伍之型「熱界雷」F・瞬身重斬最強敵並麻痺（16 秒）
- Lv18 陸之型「電轟雷轟」・普攻進化：傷害提升、雷光連鎖、第三段雷爆

## 系統

- **打擊感**：命中凍幀、螢幕震動、擊退、暴擊數字、劍氣特效、裝置震動（Android）
- **角色選擇**：首頁切換角色，等級與樓層進度各自獨立，首頁主視覺隨角色變化
- **成長**：擊殺取得經驗珠，升級提升攻擊／血量上限／防禦並回血；死亡不掉等級（roguelite）
- **裝備**：精英與頭目掉落。劍＝攻擊 +15%、範圍 +8%／件；甲＝減傷 7%、血上限 +12／件。**兩位角色共享**
- **頭目**：每 5 層一隻（守衛／稜鏡／劍鬼／雙牙／巨像／女王輪替），高難度追加限定技
- **難度**：30 層通關解鎖惡夢／地獄難度
- **續戰**：樓層進度存檔，重新整理後可從上次樓層繼續
- **RWD**：畫布依裝置長寬比動態填滿（手機直／橫、平板、桌面），平板自動放大觸控元件
